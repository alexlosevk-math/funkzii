# Функции · 9 класс

Сайт-тренажёр по функциям для ученика 9 класса: теория короткими кусками, интерактивные графики, игры и задачи уровня ОГЭ. Чистые HTML, CSS и JS — без сборки и зависимостей. Сайт открывается двойным кликом по `index.html` и без настроек работает на GitHub Pages.

## Что внутри

| Блок | Что делает ученик |
|---|---|
| 1. Функция — это машинка | крутит «машинку» вход → выход, разбирает способы задания функции, взламывает чёрные ящики, проверяет вертикальной прямой, функция ли перед ним |
| 2. График — портрет функции | ловит точки по координатам, строит параболу перетаскиванием точек |
| 3. Свойства | включает «рентген» графика: нули, промежутки знакопостоянства, рост и спад, наибольшее и наименьшее, D и E; разбирает ограниченность, непрерывность, выпуклость, чётность и план описания свойств |
| 4. Зоопарк функций | крутит ползунки у восьми видов функций (включая y = xⁿ и y = ∛x), играет в «Найди пару» (формула ↔ график) |
| 5. Сдвиги и растяжения | смотрит анимации движений, работает в лаборатории y = k·f(x − a) + b, проходит 8 уровней «Совмести графики» |
| 6. Парабола | пульт a, b, c; игра «Угадай знаки коэффициентов»; строит параболу по вершине; решает неравенства по параболе |
| 7. Босс-задачи | задачи 22 из ОГЭ с линейкой y = m, которую можно таскать |
| 8. ОГЭ: задания 11 и 22 | 8 задач на соответствие «графики ↔ формулы и коэффициенты» и 7 задач на построение графика с параметром |
| 9. Домашнее задание | 12 задач, по одной-две на каждую тему, у каждой подписана тема |
| 10. Дополнительные задания | 12 задач сложнее: несколько тем сразу, параметры, ловушки |

В конце каждого блока 1–7 есть раздел «Задачи по теме» — в каждом не меньше 7 задач.

Игры и инструменты:
- **Дуэль графиков** — стрельба функциями по мотивам Graphwar: против бота, вдвоём за одним компьютером или 10 миссий.
- **Лаборатория** — свой маленький Desmos: буквы a, b, c, k… сами становятся ползунками, кнопка «Ссылка на этот набор» копирует ссылку, которую можно отправить ученику.
- **Блиц** — 60 секунд «верно / неверно», в конце разбор ошибок.

За решённые задачи ученик получает опыт (XP) и звания. Прогресс хранится в браузере ученика (`localStorage`), на сервер ничего не уходит.

## Как выложить на GitHub Pages

1. Создай на GitHub пустой репозиторий, например `funkcii-9`.
2. В этой папке:
   ```bash
   git add -A
   git commit -m "Тренажёр по функциям"
   git branch -M main
   git remote add origin https://github.com/<логин>/funkcii-9.git
   git push -u origin main
   ```
3. На GitHub: **Settings → Pages → Source: Deploy from a branch → main / (root) → Save**.
4. Через минуту сайт будет по адресу `https://<логин>.github.io/funkcii-9/`.

Ссылки ведут прямо на нужное место: `…/#/s/shifts` — блок про сдвиги, `…/#/t/duel` — дуэль.

## Как устроен код

```
index.html          подключает всё по порядку
css/style.css       тема и общие компоненты
css/sections.css    компоненты учебных блоков
css/game.css        дуэль
js/parser.js        разбор формул без eval: 2x^2, |x-1|, sqrt(x), 3(x+1)
js/plot.js          координатная плоскость на canvas: графики, точки, перетаскивание, зум
js/ui.js            задачи с проверкой, подсказками и решением; ползунки; конфетти
js/app.js           маршруты, прогресс, XP и звания
js/sections/*.js    учебные блоки 1–10 (8 — ОГЭ, 9 — домашка, 10 — доп. задания)
js/tools/*.js       дуэль, лаборатория, блиц
```

### Добавить задачу

В любом блоке (`js/sections/…`) добавь в список ещё один `UI.task` и увеличь `tasks:` в `App.register` блока на единицу — по этому числу считается прогресс на главной.

```js
t.appendChild(UI.task({
  id: "shifts:t8",          // уникальный, с префиксом блока
  level: 2, xp: 15,          // звёзды сложности и награда
  kind: "formula",           // number | numbers | formula | choice | multi | action
  prefix: "y =",
  q: "<p>Текст задачи. Формулы — через " + m("x^2") + "</p>",
  answer: "(x-1)^2+2",       // формулы сравниваются по значениям: можно с раскрытыми скобками
  hints: ["Первая подсказка", "Вторая"],
  solution: "Разбор решения"  // кнопка «Решение» появляется после двух ошибок
}));
```

- `number` — одно число (принимает `0,5`, `1/2`, `−3`);
- `numbers` — несколько чисел через «;», порядок не важен;
- `choice` / `multi` — варианты в `options`, правильный индекс (или массив индексов) — в `answer`;
- `plot: { x: [-5, 5], y: [-4, 4], layers: [...] }` — нарисовать график прямо в задаче;
- `check: function (value) { … }` — своя проверка: вернуть `true`, `false` или текст подсказки.
